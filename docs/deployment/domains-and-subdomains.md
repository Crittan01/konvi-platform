# Domains and Subdomains

## Objetivo
Definir la estrategia de dominios del producto.

## Base prevista
- app principal
- API
- subdominios por tenant

## Ejemplos
- app.midominio.com
- api.midominio.com
- tenant1.midominio.com

## Regla importante
El subdominio mejora UX y branding, pero no reemplaza la seguridad multi-tenant.

## Futuro
Evaluar custom domains por tenant como feature premium.
