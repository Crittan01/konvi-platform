# Rollout and Rollback

## Objetivo
Definir cómo se despliega y cómo se revierte un cambio.

## Principios
- cambios pequeños y verificables
- migraciones controladas
- validación post despliegue
- rollback definido para cambios críticos

## Áreas a cubrir
- frontend
- API
- workers
- cron jobs
- DB migrations
- policies RLS
- webhooks
