# Environments

## Ambientes actuales
- local
- production

## Ambiente futuro
- staging

## Definición
### Local
La VM dedicada del proyecto.
Incluye:
- repo
- tooling
- variables locales
- ejecución de desarrollo y pruebas

### Production
Infra desplegada en:
- Render
- Supabase
- canales e integraciones externas

### Staging futuro
Réplica reducida de producción para pruebas más seguras de integraciones y despliegues.
