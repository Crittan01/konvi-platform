# Custom Store Preparation

## Objetivo
Preparar la arquitectura para una futura tienda personalizada propia que reutilice el mismo núcleo de catálogo, stock, pedidos y conocimiento.

## Principios
- el storefront no debe duplicar la lógica de negocio
- el catálogo interno sigue siendo la fuente principal
- el stock interno sigue siendo la fuente principal
- los pedidos deben entrar al mismo core transaccional

## Alcance futuro
- storefront propio
- navegación de catálogo
- detalle de producto
- checkout futuro si se decide
- integración con el mismo sistema operativo comercial
