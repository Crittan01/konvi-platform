# Support Model

## Objetivo
Definir cómo opera soporte interno y superadministración.

## Roles previstos
- superadmin
- soporte técnico
- operador interno
- admin del tenant

## Reglas
- el soporte no debe ver datos sensibles por defecto
- todo acceso especial debe quedar auditado
- el acceso debe ser mínimo y temporal cuando aplique
