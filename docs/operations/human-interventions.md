# Human Interventions

## Objetivo
Registrar todos los pasos donde el sistema no puede avanzar sin intervención humana.

## Categorías previstas
### Meta / WhatsApp
- configuración de Business Manager
- WABA
- número
- plantillas
- permisos
- revisión/aprobación

### Mercado Libre
- creación de app
- credenciales
- autorización del seller
- activación de notificaciones

### Shopify futuro
- partner account
- app config
- scopes
- instalación

### Render / Supabase
- creación de proyectos
- variables de entorno
- dominios
- DNS
- secretos

## Regla
Todo blueprint técnico debe marcar explícitamente:
- quién interviene
- cuándo
- qué necesita
- qué resultado se espera
