# Onboarding Tenants

## Objetivo
Definir el proceso de alta de un nuevo cliente.

## Pasos previstos
- crear tenant
- asignar subdominio
- crear usuarios iniciales
- cargar configuración base
- conectar WhatsApp
- conectar marketplace si aplica
- cargar catálogo inicial
- validar permisos y operación

## Regla
Todo paso manual debe estar identificado claramente.
