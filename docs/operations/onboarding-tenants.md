# Tenant Onboarding

## Objetivo
Definir el proceso de alta de un nuevo cliente en la plataforma.

## Flujo propuesto
1. Crear tenant en el sistema
2. Asignar dominio o subdominio
3. Crear usuarios iniciales y roles
4. Configurar branding mínimo
5. Configurar catálogo base o importación inicial
6. Configurar reglas operativas iniciales
7. Configurar canal WhatsApp si aplica
8. Configurar integración Mercado Libre si aplica
9. Cargar knowledge base inicial
10. Validar acceso y operación básica

## Datos mínimos del tenant
- nombre comercial
- slug
- subdominio
- owner inicial
- moneda principal
- timezone
- idioma principal
- país/región operativa

## Intervenciones humanas probables
- aprobación de subdominio y branding
- configuración Meta/WhatsApp
- autorización Mercado Libre
- carga o validación inicial de catálogo
- verificación de reglas comerciales

## Resultado esperado
El tenant debe quedar con:
- acceso funcional
- roles mínimos
- catálogo base
- configuración operativa mínima
- trazabilidad de integraciones pendientes o activas
