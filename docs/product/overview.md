# Product Overview

## Nombre funcional
Commerce Operations Platform

## Descripción
Plataforma SaaS multi-tenant para operación conversacional de e-commerce.

No es un bot aislado. Es un centro de operaciones que combina:
- backoffice
- inbox de WhatsApp
- gestión de catálogo
- variantes
- fotos y media
- stock
- pedidos
- logística
- knowledge base
- AI orchestrator
- operación interna por Telegram
- integración con marketplaces

## Propuesta de valor
Permitir que una tienda o varias marcas operen su atención, catálogo, stock y sincronización de canales desde un solo sistema, con automatización y soporte humano.

## Usuarios principales
- owner del tenant
- admin del tenant
- agentes de atención
- operador de catálogo
- operador logístico
- superadmin de plataforma

## Canales e integraciones objetivo
- WhatsApp Cloud API oficial
- Telegram Bot API para operación interna
- Mercado Libre desde la fase inicial
- Shopify preparado para fase posterior
- tienda personalizada preparada para fase posterior
