# Audit Model

## Objetivo
Definir qué acciones deben quedar auditadas.

## Eventos mínimos
- login sensible
- cambios de roles
- cambios de permisos
- cambios de productos
- cambios de stock
- cambios de pedidos
- handoff
- acciones de superadmin
- cambios de integraciones
- errores de sync importantes

## Regla
La auditoría debe permitir trazabilidad por tenant, actor y momento.
