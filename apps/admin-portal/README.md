# Admin Portal

## Estado
Reservado para una posible aplicación separada de superadministración o soporte interno.

## Nota
Por ahora, la aplicación principal del producto vive en `apps/web`.

## Regla
No implementar aquí funcionalidades hasta que la arquitectura final confirme que se necesita separar:
- panel del cliente
- panel de superadmin
- panel interno de soporte

Si no se justifica una app separada, este directorio puede eliminarse más adelante.
