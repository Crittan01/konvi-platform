# security-review

1. Revisa:
   - tenant isolation
   - RLS
   - RBAC
   - service role usage
   - webhook validation
   - file validation
   - storage access
   - admin auditability
2. Identifica riesgos de fuga de datos.
3. Propón mitigaciones concretas.
