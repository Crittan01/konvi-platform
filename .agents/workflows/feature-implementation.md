# feature-implementation

1. Lee reglas activas y documentación del módulo correspondiente.
2. Revisa dependencias de seguridad y multi-tenant.
3. Identifica documentación oficial a validar antes de tocar código.
4. Propón plan de implementación.
5. Implementa por capas:
   - modelo de datos
   - API
   - permisos
   - UI
   - tests
   - observabilidad
6. Resume riesgos y pasos manuales.
